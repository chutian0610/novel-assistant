# 产品定位：可配置混合管线，而非纯自动生成或纯人工辅助

用户最初诉求是"自动生成小说"，但网文平台围剿的是 AI 替代人做创意决策的"套利模式"，且长篇质量瓶颈在结构一致性而非文字量。我们决定：工作台的核心是一条"生成 → 检测 → 校正 → 复核"闭环管线，人工介入点做成配置项——默认每章审大纲（人机协作），也可切成全自动连跑 N 章再批量审（自动模式）。全自动与协作是同一管线的两个预设，不是两套系统。

## Considered Options

- 纯全自动流水线（一键成书）：被否，长篇质量与平台检测风险都不可接受
- 纯人机协作（每步必审）：被否，丢失"自动"的核心诉求，且日更场景需要批量信任
